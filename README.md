## ✨ About the Project

This project is a frontend recreation of the Netflix homepage, developed to practice and strengthen my web development fundamentals.

The design focuses on a dark theme, bold typography, movie poster layouts, and a clean streaming-platform interface.

> 🍿 Bringing the Netflix-inspired streaming experience to life with the power of HTML and CSS!

## 🚀 Features

- 🎥 **Cinematic Hero Section** — Dark background with a prominent headline.
- 🔥 **Trending Now** — A collection of movie and show posters.
- 🎨 **Netflix-Inspired UI** — Dark theme with red accent buttons.
- 🖱️ **Hover Effects** — Movie posters scale on hover.
- ❓ **FAQ Section** — Frequently asked questions displayed in a clean layout.
- 📧 **Email Input UI** — Email fields and Get Started buttons.
- 🌐 **Navigation Bar** — Logo, language button, and sign-in button.
- 📱 **Responsive Potential** — A foundation for further mobile-friendly improvements.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layouts, colors, and hover effects |
| SVG & Images | Logo, backgrounds, and movie posters |
